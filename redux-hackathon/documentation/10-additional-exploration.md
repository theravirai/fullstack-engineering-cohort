# Additional Exploration

Things I want to explore next or discovered outside of the basic CRUD operations:

- **RTK Query:** The documentation mentions this is the recommended way to handle data fetching and caching in modern Redux apps. It eliminates the need to write thunks for API calls manually.
- **Async Thunks:** Before diving into RTK Query, I want to learn `createAsyncThunk` to understand how Redux handles asynchronous logic like saving data to a server.
- **Redux DevTools:** I spent some time clicking around the DevTools extension. The "Time Travel" debugging feature, which lets you replay actions to see how the state changed step-by-step, is incredibly useful for fixing bugs.
