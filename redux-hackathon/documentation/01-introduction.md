# What is Redux Toolkit?

Redux Toolkit (RTK) is the official recommended way to write Redux logic. Before RTK, setting up Redux meant writing a lot of boilerplate code: action types, action creators, and large switch statements in reducers. You also had to manually add packages like `redux-thunk` and configure the store by hand.

RTK simplifies all this. It wraps the core Redux library and provides functions that make it easier to set up the store and write reducers. 

The main goal of Redux Toolkit is to speed up development by handling the messy parts of state management for us. We still get the predictable state container that Redux is known for, but with much less code.
