Browser Rendering Pipeline

How a browser processes source files (HTML/CSS) to draw pixels on the screen.

01

HTML Bytes

Raw bytes are fetched from server and decoded into characters based on document encoding.

02

Tokenization

Characters parsed into discrete HTML tokens (StartTag, EndTag, Attribute, Characters).

03

DOM Tree

Tokens are converted into nodes and linked in a tree representation of document structure.

04

CSSOM Tree

Styling rules are parsed and arranged in a stylesheet rules hierarchy.

05

Render Tree

DOM and CSSOM are combined, filtering out non-rendered elements (e.g. head, display: none).

06

Layout & Paint

Compute absolute dimensions/positions (Layout) and fill in physical screen pixels (Painting).
